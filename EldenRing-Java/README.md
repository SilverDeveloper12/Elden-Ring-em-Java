# ELDEN RING TERMINAL JAVA
<hr>

## Fangame simples de Elden Ring feito em java e jogavél no terminal com intuito do uso dos quatro principais pilares da programação orientada a objetos.

<hr>

Este fangame foi uma atividade realizada na instituição Senac SP para a matéria de Programação Orientada a Objetos. O jogo roda apenas no terminal do Java sendo necessário o próprio instalado na máquina (a partir da versão 17) para que ele rode pelo terminal do windows.

<b>
Os direitos de imagem da marca Elden Ring permanecem com as empresas Bandai Namco e FromSoftware. Este projeto tem apenas o intuito acadêmico portanto o jogo não tem intuito monetário sendo apenas um pequeno "Fan Game". 
</b>
<br><br>
Neste jogo você escolhe o nome do maculado e as armas que você irá utilizar, ele tem 3 chefes sendo eles: <b>"Godrick, o Enxertado", "Maliketh, a Lâmina Negra" e "Godfrey, o Primeiro Lorde Pristíno".</b>

<hr>

Suas armas possuem chances de acerto e munição tal que se você errar o ataque você perde o turno, mas se você escolher uma arma sem munição é possível mudar de opção.

Cada chefe possui uma mecânica diferente, mas a que mais gostei de fazer foi a mecãnica chamada <b> Morte Destinada </b> que age da seguinte forma:
<br><br>
Durante a luta contra Maliketh, a Lâmina Negra o mesmo tem uma pequena chance de realizar um ataque devastador, a pequena chance é de 5 em 100, e caso um sorteio criado para verificar se ele tem a capacidade de realizar dito ataque seja verdadeiro, então Maliketh irá derrotar o player independentemente da vida do mesmo. Esta mecânica utiliza o conceito do polimorfismo pois a classe que armazena o ataque de Maliketh é sobreescrita e armazena a chance da Morte Destinada, o sorteio acontece a cada fim de turno do player e quando Maliketh atinge 200 de vida ele ganha um buff que aumenta a chance para 20! então o player precisa ser cauteloso a escolher o próximo ataque.
<br><br>
O jogo já tem um fim, mas eu diria que ele está bem desbalanceado além de meio ilegível pela velocidade que o texto corre pela tela, porém como dito antes o jogo foi criado a partir de um trabalho na minha faculdade e eu me diverti muito fazendo baseado em um jogo que tenho tanto apreço por.
